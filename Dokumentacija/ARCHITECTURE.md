# Architecture

Autosalon OneZone is an ASP.NET Core MVC application built around a classic MVC structure, Entity Framework Core persistence and ASP.NET Core Identity authentication.

## High-Level Overview

```text
Browser
  |
ASP.NET Core MVC
  |
Controllers + ViewModels
  |
Services
  |
Entity Framework Core
  |
SQL Server
```

## Presentation Layer

- Razor Views
- Bootstrap 5 UI
- Shared layout
- Reusable partial views
- Resource-based localization through `.resx` files

## Controller Layer

Controllers process requests, validate input and coordinate view models, EF Core data access and services.

Main controllers:

- `AccountController`
- `AdminPanelController`
- `VoziloController`
- `KorpaController`
- `ProfilController`
- `HomeController`
- `LanguageController`

## Data Layer

- `ApplicationDbContext`
- EF Core migrations
- SQL Server
- Domain entities for users, vehicles, carts, orders, payments, reviews and support inquiries

## Identity and Authorization

The application uses ASP.NET Core Identity for:

- password hashing
- role-based authorization
- secure password reset tokens
- anti-forgery protection on POST forms

Main roles:

- Administrator
- Prodavac
- Kupac

## Services

Services isolate infrastructure and integrations from controllers:

- payment abstraction
- mock payment service
- Stripe-ready payment service
- Resend email sender

## Localization

Localization uses:

- `SharedResource`
- `Resources/SharedResource.en-US.resx`
- `Resources/SharedResource.bs-Latn-BA.resx`
- `LanguageController`
- request culture cookie

The default culture is `en-US`, and the additional supported culture is `bs-Latn-BA`.

## Password Reset Flow

1. The user enters an email address.
2. The application generates an ASP.NET Core Identity reset token.
3. The token is embedded in a reset link.
4. If Resend is configured, the email is sent to the user.
5. If Resend is not configured in Development mode, the link is written to the application log.
6. The user opens the link and sets a new password.

## Security Notes

- API keys are not stored in source code.
- Resend and Stripe configuration comes from environment variables.
- Password reset tokens are generated by ASP.NET Core Identity.
- Reset links expire after 30 minutes.
- Admin actions are protected by role-based authorization.
- Destructive actions use controlled UI confirmation modals.
- Browser `alert()` and `confirm()` dialogs are avoided.

## Docker Runtime

Docker Compose starts:

- SQL Server container
- ASP.NET Core web container

On startup, the application applies migrations and seeds demo data.
